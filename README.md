# Forest of An-Ylthin

A dark fantasy turn-based tactical strategy game built with React, TypeScript, and Vite.

## Requirements

- **Node.js**: `v20.0.0` or higher
- **npm**: `v9.0.0` or higher

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rodriagusdev/forestofanylthin.git
   cd forestofanylthin
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Run tests:**
   ```bash
   npm test
   ```
